IT World saytiga xush kelibsiz!

Ushbu saytda kompyuter, noutbuk, operatsion tizimlar, Microsoft Office, internet, dasturlash va texnologiyalar haqida foydali ma’lumotlar topasiz.

Kompyuter — ma’lumotlarni qabul qilish, qayta ishlash, saqlash va natijalarni chiqarish uchun ishlatiladigan elektron qurilma.

Kompyuter qismlari

🧠

Protsessor (CPU)

Kompyuter buyruqlarini bajaradi va hisob-kitoblarni amalga oshiradi.

🎮

Videokarta (GPU)

Rasm, video, 3D grafika va o‘yin tasvirlarini qayta ishlaydi.

🧩

Operativ xotira (RAM)

Ishlayotgan dasturlar ma’lumotlarini vaqtincha saqlaydi.

💾

SSD

Fayllarni saqlaydi. Odatda tez ishlaydi va harakatlanuvchi mexanik qismlari yo‘q.

📀

HDD

Ma’lumotlarni magnit disklar yordamida saqlaydigan qurilma.

🖥️

Monitor

Matn, rasm, video va dastur oynalarini ekranda ko‘rsatadi.

⌨️

Klaviatura

Matn yozish, buyruq berish va kompyuterni boshqarish uchun ishlatiladi.

🖱️

Sichqoncha

Kursorni harakatlantirish, fayl tanlash va dasturlarni ochishga yordam beradi.

🔌

Quvvat bloki

Elektr energiyasini kompyuter qismlari uchun mos quvvatga aylantiradi.

🧱

Ona plata

Protsessor, RAM va boshqa qismlarni bir-biriga ulaydi.

🌬️

Sovitish tizimi

Ventilyator va radiatorlar yordamida qizib ketishni kamaytiradi.

🎧

Quloqchin

Ovozlarni shaxsiy tinglash uchun ishlatiladi.

Windows operatsion tizimlari

Windows — Microsoft kompaniyasi ishlab chiqqan operatsion tizimlar oilasi.

🪟

Windows 1.0

1985-yilda chiqarilgan ilk Windows versiyasi.

🪟

Windows 2.0

1987-yilda chiqarilgan, oynalar bilan ishlash imkoniyatlari yaxshilangan.

🪟

Windows 3.1

1992-yilda ommalashgan grafik interfeysli tizim.

🪟

Windows 95

1995-yilda chiqarilgan. Start menyusi va vazifalar paneli bilan mashhur.

🪟

Windows 98

1998-yilda chiqarilgan, internet va qurilmalar bilan ishlash yaxshilangan.

🪟

Windows 2000

2000-yilda taqdim etilgan, biznes va ish muhitida ishlatilgan.

🪟

Windows XP

2001-yilda chiqarilgan va uzoq vaqt mashhur bo‘lgan.

🪟

Windows Vista

2007-yilda chiqarilgan, yangi ko‘rinish va xavfsizlik imkoniyatlariga ega.

🪟

Windows 7

2009-yilda chiqarilgan va ko‘plab foydalanuvchilar orasida mashhur bo‘lgan.

🪟

Windows 8

2012-yilda chiqarilgan, bosh ekran dizayniga urg‘u berilgan.

🪟

Windows 8.1

Windows 8 uchun yangilangan versiya, 2013-yilda taqdim etilgan.

🪟

Windows 10

2015-yilda chiqarilgan, ko‘plab kompyuterlarda ishlatiladi.

🪟

Windows 11

2021-yilda chiqarilgan, yangilangan dizayn va tizim imkoniyatlariga ega.

Eslatma: Windows 10’ning odatiy qo‘llab-quvvatlashi 2025-yil 14-oktabrda tugagan. Windows 11 uchun kompyuter tizim talablari mavjud.
